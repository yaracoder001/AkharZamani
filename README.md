# ربات بازی جنگ جهانی (روبیکا) - نسخه اولیه

Node.js (۱۸ به بالا) + MongoDB + کتابخانه‌ی mongoose. بدون وابستگی به کتابخانه‌ی روبیکا؛ مستقیم با Bot API v3 و روش getUpdates کار می‌کند.

## راه‌اندازی
1. `npm install`
2. فایل `.env.example` را به `.env` تغییر نام بدهید و مقادیر را پر کنید (توکن، رمزها، آدرس مونگو).
3. `npm start`
4. ربات را به گروه اعلان‌ها اضافه کنید (ترجیحا ادمین گروه)، سپس ابتدا در خصوصی وارد پنل مدیریت اصلی شوید و داخل گروه بنویسید: `ثبت گروه`
   (یا شناسه گروه را در `ANNOUNCE_CHAT_ID` بگذارید).

## عکس‌های اعلان (کنار package.json بگذارید؛ jpg یا png)
| نام فایل | کاربرد |
|---|---|
| `shipment.jpg` | اعلان ارسال محموله (کمک / انتقال) |
| `attack.jpg` | اعلان ارسال محموله‌ی حمله |
| `shootdown.jpg` | اعلان سرنگونی محموله |

اگر عکس نباشد، اعلان به صورت متن ارسال می‌شود.

## ورود به پنل‌ها
- رمز مدیریت اصلی: `OWNER_PASSWORD` و رمز ادمین: `ADMIN_PASSWORD` در فایل `.env`.
- ادمین علاوه بر رمز باید توسط مدیریت اصلی تعریف شده باشد (مدیریت ادمین‌ها > افزودن ادمین، با شناسه‌ی کاربر؛ کاربر با دکمه‌ی «شناسه من» آن را می‌بیند).
- با تغییر رمز در `.env` و راه‌اندازی مجدد، همه‌ی نشست‌های قبلی خودکار باطل می‌شوند.
- بازیکن‌ها با «کد کشور» وارد بازی می‌شوند که از پنل مدیریت یا ادمین ساخته می‌شود.

## قابلیت‌ها
**بازیکن:** وضعیت کشور، برداشت درآمد (تا ۲۴ ساعت ذخیره)، ارتقاء معادن نفت/طلا/گاز/مس، پادگان، بانک و سه پدافند (هوایی، زمینی، دریایی)، خرید نیرو (تانک، جنگنده، پهباد، موشک، ناو، زیردریایی)، حمله زمینی/هوایی/دریایی، ارسال محموله‌ی کمک، سرنگونی محموله با کد رهگیری، ارسال بیانیه به گروه (با لینک آیدی ارسال‌کننده) و درخواست خرید پک.

**محموله‌ها:** اعلان داخل گروه با عکس، کد رهگیری و زمان تقریبی ۵ دقیقه (`TRAVEL_MINUTES`). در این مدت هر کشور دیگری می‌تواند با پدافند هوایی خود آن را سرنگون کند.

**مدیریت اصلی:** ساخت کشور و صدور کد، لیست همه‌ی کشورها و کدها، نابودی کشور، آزادسازی کشور برای بازیکن دیگر (کد جدید صادر می‌شود)، ساخت پک پولی (ربات می‌پرسد برای چه بخشی: منابع، ارتقاء سطح، سرباز، جنگنده، موشک، پهباد، نیروی زمینی، ناو و زیردریایی یا میکس)، تایید/رد سفارش پک، هدیه همگانی به همه‌ی کشورها، مدیریت ادمین‌ها و کاربران (مسدود/رفع مسدودیت)، پیام همگانی.

**ادمین (محدود):** ساخت کشور و صدور کد، لیست کشورها (بدون کد)، اطلاعات کشور.

## نکات
- پک‌ها فقط با پول واقعی خریداری می‌شوند: کاربر درخواست می‌دهد، کد سفارش می‌گیرد و متن `PAYMENT_INFO` را می‌بیند؛ بعد از پرداخت، مدیریت از «سفارش‌های پک» آن را تایید می‌کند.
- همه‌ی عددهای بازی (هزینه‌ها، درآمدها، قدرت نیروها) در `src/game.js` هستند و راحت تغییر می‌کنند.
- استایل متن‌ها (مونو و نقل‌قول) با مارک‌داون روبیکا است: ``` `متن` ``` و `> متن`.
